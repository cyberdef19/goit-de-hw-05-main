Скрипти репозиторія демонструють роботу продюсерів у вигляді імітованих сенсорних датчиків, що надсилають дані до топіків Kafka, а також консюмерів, що зчитують дані з топіків.

Скрипт topics.py створює топіки у віддаленому Кафка. Скрипт print_topics дозволяє переглянути доступні топіки за відповідним токеном. Скрипт producer.py надсилає дані по температурі та вологості до новостворених топіків. Скрипт building_consumer.py створює консюмера та підписується на топік. Коли він отримує дані з топіка при обробці відбувається фільтрація алертів температур та вологості і водночас створення продюсерів, котрі відправляють алерти по топікам алертів температури та вологості. Скрипт alerts_consumer.py отримує дані з топіків алертів та демонструє їх.
